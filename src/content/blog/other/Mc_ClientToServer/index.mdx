### 安装模组加载器服务端

我们需要到对应的模组加载器官网下载一个`.jar`文件，我么需要使用这个`.jar`文件构建服务端，此外我们也需要对应的java版本（可以去搜索一下）。<br/>
这里我以`neoforge`为例
![[3.png]](./3.png)

下载后放在之前打包好的服务端文件夹中。如下图所示：
![[4.png]](./4.png)
为了方便区分可以将上述图片中后缀为`.bat, .sh, .ps1`的文件删掉。<br/>
现在需要下载服务端的包了，每个模组加载器的命令不一致需要参考加载器官方的使用文档。<br/>
打开终端执行命令，这个步骤需要保证安装了`java`,终端打开打包好的服务端文件夹。执行一下命令：
```shell
java -jar ./neoforge-21.1.172-installer.jar --installServer
```
**需要将`neoforge-21.1.172-installer.jar`换为自己对应的文件名称**<br/>

执行完成后会发现有后缀为`sh`或`bat`的文件生成，现在新建一个文件命名为`eula.txt`，至于有什么用可以自己查询下官方的解释，内容为：
```
eula=true
```
如果你是`windows`系统可以直接双击`.bat`后缀的文件，`linux`系统在终端执行*bash ./run.sh*(run.sh 替换为实际名称)

## 部署
选择合适的服务器，如果是新手可以尝试使用面板安装。<br/>
部署时只需要将无问题的服务端文件上传到服务器，最后执行上述生成的`run.sh`或`run.bat`文件即可。最后配置一下端口即可。
